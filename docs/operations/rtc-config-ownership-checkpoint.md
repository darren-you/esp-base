## 所有权与不变量

原 C3 普通 RAM 中的 `protocol_state_t` 为 7640 字节，同时在 RTC 中保留 7618 字节编码缓冲。实现将前者放入 RTC；C3 只在 config load、规范字节消费或已验证 commit 的整个操作中申请一份 7618 字节普通 RAM 缓冲。load／写入／持久读回共用这份 owner，返回前清零释放；申请失败不开始 NVS 访问，load 输出和 committed 输出保持。callback 返回后字节借用结束。

RTC 可能跨深睡保留，因此每次开始启动配置加载前明确清空 context，重新从 NVS 取得已提交事实；不以 RTC 内容代替持久化或确认依据。ESP32 延续原 8BIT IRAM 长期 context 和 RTC 编码缓冲策略。两目标配置 v3、canonical EBCF 字节、revision、冲突／耗尽／写后不确定语义、namespace／key、公开头文件和字段上限均保持。

固定 SDK C3 的真实 ELF 确认 context 位于 `0x50000000`，尺寸 7640 字节，RTC 区无溢出；不再有静态 `s_config_bytes`。这一位置和尺寸检验不能机械换算为整机堆收益。
