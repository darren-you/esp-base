# P6-03：Base 控制任务与 MQTT 配置工作区复用检查点

2026-09-28。Base 控制任务在启动和配置 revision 变化时同步调用 `esp_base_mqtt_owner_configure`；`emqtt_create` 在返回前按值复制 MQTT 配置。控制任务的命令解析只发生在该调用之外，配置提交用的命令配置字段也在调用前完成读回与校验。因此命令解析结构 `ebase_command_t` 与建连输入 `emqtt_config_t` 共用一个静态 union，由控制任务把后者短时借给 MQTT owner；owner 在有效调用前后清零借用区。收到 MQTT MESSAGE 时，事件及其 payload 仍可能在命令回调期间使用，所以 `emqtt_event_t` 保留独立缓冲，未与命令区叠放。配置 wire、TLS 校验、Topic、owner 状态机和外部依赖锁均不变。
